# VPN Unifier

Собирает конфиги VPN из **Telegram-каналов**, **GitHub-репозиториев**, **ссылок-подписок** и локальных **.txt** файлов в один единый конфиг. Перед добавлением серверы проверяются на доступность (TCP-пинг с высокой параллельностью), мёртвые уходят в отдельный файл, сомнительные остаются в основном конфиге. В комплекте — готовый сайт для **Vercel**, который раздаёт конфиг как подписку для Happ / V2rayTun / Streisand / v2rayNG.

## Возможности

- 📡 **Telethon-сканирование каналов**: `t.me/SlivVpn`, `t.me/PluginHappv2rayTun` (+ любые свои)
- 📦 **GitHub-репозитории**: конфиги из корня `igareck/vpn-configs-for-russia`
- 🔗 **Внешние подписки**: goida-vpn-configs (26.txt), cdn-assets и любые свои URL
- 📄 **Локальные .txt**: все файлы в папке `sources/` (ваши ключи уже в `sources/input.txt`)
- 🧹 **Фильтрация**: Telegram-прокси отбрасываются, `.conf`-файлы игнорируются, vless добавляются как есть
- 🚀 **Импорт «полноценных конфигов»**: base64-подписки, Clash YAML, JSON-массивы — всё переводится в обычные ссылки
- ⚡ **Проверка пинга**: до 300 параллельных TCP-проверок, кэш результатов (12 часов) — повторные запуски почти мгновенны
- 📊 **Статистика**: топ-5 самых быстрых серверов, разбивка по протоколам
- 🌐 **Сайт на Vercel** с красивой страницей, QR-кодом и автообновлением через GitHub Actions

## Вывод

| Файл | Назначение |
|---|---|
| `output/unified_config.txt` | Единый конфиг (ссылки построчно) |
| `output/unified_config_b64.txt` | То же в base64 (формат подписки) |
| `output/dead_servers.txt` | Мёртвые серверы |
| `output/clash.yaml` | Clash-конфиг |
| `output/stats.json` | Статистика для сайта |
| `web/data/*` | Копии для деплоя на Vercel |

## Установка и запуск

```powershell
pip install -r requirements.txt
python main.py
```

При первом запуске мастер задаст пару вопросов (можно просто жать Enter).

### Telegram-сессия

1. Зайдите на https://my.telegram.org → «API development tools» → создайте приложение.
2. Запишите `api_id` и `api_hash` (можно указать в переменных окружения `TELEGRAM_API_ID` / `TELEGRAM_API_HASH` — тогда при запуске они подхватятся автоматически, иначе Telethon спросит сам).
3. Положите файл сессии в папку `session/` (например, `session/vpn_unifier.session`) либо укажите путь: `python main.py --session session/my.session`.
4. При первом запуске Telethon запросит номер телефона и код — после входа сессия сохранится.

## Основные флаги

```
--no-telegram        не сканировать Telegram
--no-github          не сканировать GitHub
--no-urls            не качать внешние подписки
--no-local           не читать папку sources
--channels "url1,url2"   свои каналы
--tg-limit 300       сколько сообщений брать с канала
--no-check           не проверять серверы (мгновенно)
--fresh              игнорировать кэш проверок
--strict-dead        «неизвестные» тоже отправлять в мёртвые
--max-total 3000     лимит серверов в конфиге
--protocols vless,vmess,trojan   фильтр протоколов
--timeout 5 --concurrency 300    параметры проверки
--no-clash           не генерировать clash.yaml
--ci                 режим для GitHub Actions (сессия из env)
```

## Сайт на Vercel

1. Залейте проект в GitHub-репозиторий.
2. На vercel.com: **Add New Project** → выберите репозиторий → в настройках укажите **Root Directory = `web`**.
3. Deploy. Ссылка-подписка будет вида `https://ваш-сайт.vercel.app/sub`.

### Автообновление конфига

В репозитории лежит workflow `.github/workflows/update.yml` — раз в сутки (и по кнопке в Actions) он собирает свежий конфиг и пушит его в `web/data/`, Vercel автоматически передеплоивает сайт.

В настройках GitHub-репозитория → **Settings → Secrets and variables → Actions** добавьте:

| Secret | Значение |
|---|---|
| `TELEGRAM_API_ID` | ваш api_id |
| `TELEGRAM_API_HASH` | ваш api_hash |
| `TELEGRAM_SESSION` | строковая сессия: запустите локально `python main.py --ci`-совместимый дамп либо `python -c "from telethon.sync import TelegramClient; ..."` — проще всего получить командой: `python tools/export_session.py` (локально, с уже авторизованной сессией) |

## Настройка источников

Все источники правятся в `config.py`:

- `TELEGRAM_CHANNELS` — список каналов
- `GITHUB_REPOS` — репозитории (берутся файлы из корня)
- `RAW_URLS` — внешние подписки (с лимитом узлов на каждую)
- `sources/*.txt` — свои ссылки (папка читается целиком)

Скорость проверки: 2000 серверов проверяются примерно за 40–70 секунд. При повторном запуске в течение 12 часов кэш делает запуск почти мгновенным.
