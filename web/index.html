Ссылка-подписка

Ссылка обновляется автоматически. Добавьте её в приложение — и все серверы появятся сразу.

Отсканируйте QR-код камерой телефона или прямо из приложения Happ / V2rayTun / Streisand.

Как подключить

Happ (iOS)
1. Откройте Happ → «Профили».
2. Нажмите + → «Импорт по ссылке».
3. Вставьте ссылку-подписку сверху и нажмите «Скачать».
4. Выберите сервер из списка и нажмите кнопку подключения.
V2rayTun (iOS)
1. Откройте V2rayTun → «Плюс» → «Добавить подписку».
2. Вставьте ссылку-подписку, дайте имя и сохраните.
3. Обновите подписку и выберите узел.
Streisand (iOS)
1. Streisand → «Добавить подписку».
2. Вставьте ссылку-подписку.
3. Готово — серверы появятся автоматически.
v2rayNG (Android)
1. Откройте меню (≡) → «Настройки подписки».
2. Нажмите +, вставьте ссылку-подписку.
3. Вернитесь назад → значок обновления рядом с подпиской.
Hiddify / NekoBox / sing-box
Вставьте ссылку-подписку в раздел «Новый профиль → Добавить из URL». Для Hiddify также доступен вариант /sub/clash.
